# 🧠 Conversational Agent

A conversational agent with persistent episodic memory built with:
- **LLM**: HuggingFace Inference API
- **Embeddings**: sentence-transformers
- **Vector DB**: ChromaDB
- **UI**: Gradio

## Features
- Remembers past interactions using RAG
- Dynamic memory retrieval based on semantic similarity
- Clean and simple chat interface
